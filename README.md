# CARATS BY GRACE

> **Haute Joaillerie & Rare Type IIa Natural Diamonds**

An editorial luxury e-commerce and private concierge web application built with **Node.js**, **Express**, and modern responsive web standards.

---

## ✨ Features

- **Luxury Design System**: Alternating deep oxblood (`#240812`) and warm alabaster (`#FAF7F2`) color scheme, editorial serif typography (*Cormorant Garamond* / *Cinzel*), and fine champagne gold accents.
- **Top Luxury Bar**: Live appointment status indicator, real-time multi-currency converter (`USD $`, `GBP £`, `EUR €`), and direct concierge hotline.
- **Hero Showcase**: Featuring archival Type IIa diamond ring presentation with floating private vault viewing card.
- **The Lapidary Dossier**: Interactive archival stone selector with spectroscopic provenance and 4-block grading matrix (`Carat`, `Clarity`, `Color`, `Cut`).
- **The Gemological Atelier**: 4-pillar craftsmanship standards (*Facet Artistry*, *Cold-Forged Platinum*, *Optical Symmetry*, *Bespoke Prongs*).
- **The Optical Proportion Matrix**: Comparative gemological analysis table and **Interactive HTML5 Ray-Tracing Simulation** rendering real-time light reflection and refraction paths across diamond cut grades.
- **Masterpieces & Solitaires**: Dynamic category filter tabs, high-jewelry product cards, currency conversion, and instant gemological specs modal.
- **Audience by Appointment & Concierge**: Interactive global salon picker (*Mayfair London*, *Place Vendôme Paris*, *Manhattan New York*, *Armored Global Courier*) paired with a private invitation reservation form.
- **Backend API**: Built-in Express REST endpoints for pieces, dossiers, salon reservations, and confidential newsletter subscriptions.
- **Responsive Architecture**: Fully responsive and tested across desktop (1440px+), tablet (768px - 1024px), and mobile (< 768px) with dedicated slide-out drawer and sticky quick-action bar.

---

## 🛠️ Tech Stack

- **Backend**: Node.js, Express.js
- **Frontend**: Vanilla Semantic HTML5, Modern CSS (Grid, Flexbox, Custom Properties), JavaScript (ES6+)
- **Graphics**: HTML5 Canvas Ray-Tracing Engine, SVG iconography

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/parasnath215/caratsbygrace.git
   cd caratsbygrace
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the application:
   ```bash
   npm start
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
